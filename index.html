YYC CAD Export

Turn a Revit sheet into a drawing the Calgary Airport Authority will accept: ten steps, one AutoCAD toolkit that does most of the work, and the reasons behind each step for when you need them.

Also needed: the Revit export settings file (.rvt, 35 MB). Download it here and save it in folder 4 of the kit.

Set up once

One time per computer. After this, every drawing starts at step 1.

  1. Unzip the kit somewhere it can stay.

    The tools keep pointing at its Kit folder, so don’t leave it in Downloads.

  2. Unzip the add-in and copy YYC-CADTools.bundle into %APPDATA%\Autodesk\ApplicationPlugins

    Close AutoCAD first. Paste the path into the File Explorer address bar; create the ApplicationPlugins folder if it isn’t there.

  3. Start AutoCAD and open the YYC Export tab.

    Every command is a button, left to right in process order. You don’t have to type anything: each step below names its button. No tab? Right-click the ribbon → Show Tabs → YYC Export.

  4. YYCPROFILES

    Set Kit folder to the kit’s 1 - Kit folder, click Fill empty files from the kit folder, check the grid, type a description and drawing number, then Save + use. Make one profile per terminal (04 Domestic, 20 International).

  5. YYCMAKEREF

    In a new, empty drawing. Builds the layer reference the tools and LAYTRANS compare against.

Updating to a new kit: copy the new bundle over the old one. Your profiles are kept.

1In Revit

Export from Revit

Bring the YYC DWG export setup into your project once, then export with it, so layers, colours and the titleblock come out the way the rest of the steps expect.

Run

  1. Open your project and RVT.Export.Settings._.YYC.AR.rvt from folder 4 of the kit.

  2. In your project: Manage tab → Transfer Project Standards.

    Copy from the YYC file, click Check None, tick only DWG/DXF Export Setup Settings, then OK.

  3. Export → CAD Formats → DWG, and pick the YYC AR setup.

    Batch or one sheet at a time. Either name each file as you export, or export everything and rename it all in step 2, but don’t mix the two.

Your disciplineYYC AR is set up for architecture. Adjust its layers for your discipline, and add status modifiers (DEMO, NEWW…) if the project has phases.

2Ribbon panel Sheet

Name the files

The file name is the YYC drawing number plus the sheet number, with no periods, dashes or spaces. It’s the name the Airport Authority files forever, so do it before anything else.

Run

  1. YYCRENAME on the export folder

    From a blank drawing: AutoCAD can’t rename a file that’s open. It shows a preview and asks before renaming.

Manual method and notes 
YYC drawing number (example): 24X123
A102        →  24X123A102.dwg
A-201       →  24X123A201.dwg
AD.201      →  24X123AD201.dwg    demolition
M-201.01    →  24X123M20101.dwg   no separators

The drawing number is assigned by the Airport Authority’s PM at project start.

Note

Rename before you start on layers. Renaming a file you’ve already cleaned, and re-pathing its xrefs, is how a sheet gets done twice.

3Ribbon panel Sheet

Page setup

Revit doesn’t export exactly to A0. The titleblock is right; the sheet size isn’t. The page setup in the YYC titleblock template fixes it.

Run

  1. YYCPAGESETUP

    Applies the “YYC - Titleblock” page setup to every layout and moves the sheet onto 0,0. If nothing seems to change, type RE and the A0 size shows.

Manual method and notes

Page Setup Manager → Import → YYC Titleblock - Revit Export_A0.dwt from the Kit folder → set current on the layout.

Sheet border and titleblock live in paper space; the plan, notes, dimensions and symbols live in model space. The layout origin is the lower-left corner of the border, and layouts plot at 1:1.

Note

You import it once and it stays on your machine for every drawing. If it isn’t in the list, it hasn’t been imported on this workstation yet.

4Ribbon panel Sheet

Schedules to paper space

Revit puts schedules and sheet notes in model space. They belong on the sheet, in paper space.

Before step 5Do this before the drawing moves onto the grid. Once model space has moved, you can no longer tell where the schedules sit behind their viewports.

Run

  1. YYCSCHEDULES

    On the layout, click a schedule viewport’s frame. What it shows moves to paper space at the same size and spot, then it offers to delete the empty viewport. One at a time; Enter to finish.

  2. Anything left over: CHSPACE.

NoteDon’t copy and paste between spaces. It doesn’t rescale, so the schedule text comes out the wrong size.

Manual method and notes 
on the layout, with the viewport active
Command: CHSPACE          alias CHSP
Select objects:           the schedules / sheet notes
AutoCAD rescales them for the new space
5Ribbon panel Grid

Land it on the YYC grid

The export sits near Revit’s origin; the YYC grid sits out at the airport coordinate system, kilometres away. The drawing moves onto the grid. The geometry is never rotated to look right.

Run

  1. YYCGRIDIN

    Inserts your profile’s grid (04 DTB or 20 ITB) at 0,0,0 as one block.

  2. YYCALIGNREC on the first sheet of a terminal

    The same four clicks as ALIGN, never scales. It moves model space, turns the drawing viewport to match, and remembers the move.

  3. YYCALIGNAPPLY on every other sheet

    Repeats the recorded move with no clicks.

NoteDon’t MOVE anything by hand first. The recording only knows its own clicks.

NoteWhen aligning by hand, always answer N to scaling: Yes quietly resizes the whole plan. Pick the two points far apart.

Apply Move lands a sheet in the wrong place?

That export didn’t come out of Revit at the same position as the sheet you recorded, usually a different model, area or terminal. It needs its own profile with its own recorded move.

  1. Close the drawing without saving and open it again.

    Apply Move marks a drawing as moved, so start from the clean export.

  2. YYCPROFILES

    Select the profile you’ve been using, type a name in New (for example DTB Area 4), click Add. It copies the kit files and settings.

  3. Set Grid move to Its own recording, check the grid, then Save + use this profile.

  4. YYCALIGNREC

    Record this export’s move with the four clicks. Every other sheet from the same export: YYCALIGNAPPLY.

Switching backOpen YYCPROFILES, pick the other profile, click Save + use this profile. Every command prints Profile: … first, so check it before you run Apply Move.

6Ribbon panel Grid

Remove the grid, purge

The grid was scaffolding, and it drags in its own layers and blocks. Clear them now so they don’t clutter the layer work in step 8.

Run

  1. YYCGRIDOUT

    Deletes the grid block and its definition.

  2. YYCCLEAN

    Deletes empty text, purges three times, audits.

  3. YYCFIND0

    Lists any $0$ names left over from binding.

Manual method 
Delete the grid block     one click
Command: PURGE            tick “Purge nested items”, run twice
Command: AUDIT            Fix any errors detected? Y
7Ribbon panel Viewports

Viewports

The sheet reads project north; model space stays at true coordinates. Step 5 already turned the drawing viewport and gave it a matching YYC Project North UCS. This step finishes it.

Run

  1. YYCVPLAYERS

    Puts each viewport on its own VIEWPORT1, VIEWPORT2… layer, set to no-plot.

  2. Check the crosshairs.

    Double-click into the drawing viewport: the crosshairs should line up with the plan and ortho should run along the walls. If not, run YYCVPUCS. Double-click outside: the crosshairs should be square to the sheet again. If they’re tilted, type UCS then W.

  3. Check the viewport scale.

  4. YYCVPLOCK

    Locks every viewport, and offers to snap a drifted scale (1:97.3) back to the standard one first.

NoteMore VIEWPORT# layers than viewports, for example after YYCSCHEDULES deleted some? Run YYCVPLAYERS again, then YYCCLEAN to purge the empty layers.

Never rotate the geometry“DO NOT ROTATE OR MOVE THE ELEMENTS THEMSELVES.” CADD Manual §2.4, their capitals. Turning geometry breaks its relationship to every other drawing on site.

Manual method and notes
  1. Unlock the viewport and pan to the right part of the building.
  2. Set the scale.
  3. Turn the UCS, not the drawing, so the plan sits square on the sheet.
  4. Check the scale again, then lock the viewport.
double-click inside the viewport
Command: UCS              OB, pick a line along the radial grid (or Z and an angle)
Command: PLAN
<Current UCS>: C

YYC checks two things on delivery: viewports on VIEWPORT# layers set to no-plot, and every viewport locked at the right scale with the main layout active.

Note

Each area has its own angle off north. Build one viewport carefully for a new area, then copy it to every other sheet in that set.

8Ribbon panel Layers

Layers

The longest step, and where compliance is won or lost. Every layer gets a YYC name and YYC settings, and nothing stays on layer 0.

Run

  1. Map the layers

  2. YYCLWDEFAULT

    Sets every lineweight to Default. Revit stamps its own; at YYC the colour sets the pen weight.

  3. YYCLAYXL

    Writes every layer into YYC Layer Mapper.xlsx and opens it.

  4. Pick what you can in Excel, then save.

    Work down the CHOOSE rows and pick a YYC layer from the dropdown in YOUR CHOICE. Not sure? Leave it blank. To merge, pick a layer that’s already in the drawing.

  5. YYCLAYMAP

    Renames and merges as you chose, and remembers every choice.

  6. YYCLAYSYNC

    Sets colour, linetype, lineweight, plot and missing descriptions to the standard.

  7. Layer 0

  8. YYCZERO

    Selects what’s on layer 0 and DEFPOINTS. Only loose lines or text? Move them to the right layer and skip to the walk.

  9. YYCPARK

    Moves each selected block to its own spot left of the drawing, 200 000 mm apart.

  10. Explode the parked blocks.

  11. Map the new layers: YYCLAYXL → pick → YYCLAYMAP → YYCLAYSYNC

    Exploding brings in layers that were inside the blocks.

  12. Walk and finish

  13. Walk the layers.

    LAYWALK to look through every layer quickly. YYCLAYWALK to map or merge what’s still not YYC: Show it isolates the layer, pick its YYC layer, Map.

  14. Check every layer once more.

  15. YYCUNPARK

    Puts the parked pieces back exactly where they came from. Only once the layers are done.

Any timeYYCLAYXL, YYCLAYMAP and YYCLAYSYNC can be run at any point, as many times as you need on each file. Each run picks up what’s in the drawing now.

RememberedThe only thing you save is the Excel file, after picking. YYCLAYMAP and YYCLAYWALK write each choice into the workbook’s Library sheet and save it themselves. On the next drawing, YYCLAYXL marks those layers REMEMBERED with your choice already filled in. Revit numbers don’t matter: A-WALL-3 is remembered as A-WALL. Keep one Layer Mapper per project, the one your profile points to.

Manual method and notes

Two different problems

The YYC standard has more and different categories than Revit maps to; that’s the renaming. And objects land on the wrong layer even when the mapping is right, MEP families especially; that’s the walk.

Layer Translator — LAYTRANS

ControlWhat it does
LoadLoads the target list: YYC Layer Reference - CADD Manual v6.2.dwg (or .dws) in the Kit folder.
Map SameMatches every layer already named the same on both sides. Click it first.
Selection FilterWildcards: A-ANNO* grabs every annotation layer.
MapSends the selected layers to the highlighted target.

SettingsTick Force object colour and linetype to BYLAYER, Translate objects in blocks, Write transaction log.
One pass per job

Don’t map everything and translate once. Give each pass one job: titleblock lines, then construction lines, then grid linetypes, then colours. Run it, check it, save the mapping, next.

Modifier layers

A status modifier goes in as a fourth field: A-WALL-DEMO is A-WALL plus DEMO. The manual (4.1.6) gives no colour or linetype for them; only -NPLT has a rule, no plot. The toolkit gives them the parent’s colour (the colour is the pen weight) and Default lineweight, and keeps the exported linetype, so a dashed DEMO stays dashed.

Status modifiers: DEMO · EXST · FUTR · MOVE · NEWW · NICN · NPLT · PRPS · RELO · TEMP

Walking the layers

Correct names don’t mean correct contents. An MEP family can export to the right layer while its symbol lands on a generic annotation layer. No spreadsheet catches that; you have to look.

Ctrl+A, then SETBYLAYER   first: LAYWALK can hide objects coloured by entity
Command: LAYWALK          tick “Restore on exit”
LAYISO / LAYUNISO         isolate a selected object’s layer, and undo
LAYMRG                    merge one layer into another
Note

The walk is slow and there’s no shortcut. Budget the time; this is exactly the error that comes back from YYC as a rejected submission.

The park step helps, but it only moves what you select. Picking through YYCZERO is what makes it work: it selects exactly what’s on layer 0.

9Ribbon panel QA

Final QA

What the Airport Authority checks on receipt (CADD Manual §5.15). The report changes nothing; it tells you what to fix.

Run

  1. YYCCLEAN

  2. YYCFINAL

    Locks viewports, makes the main layout active, zooms extents.

  3. YYCQA

    This drawing, or a folder. Writes YYC QA Report <date>.xlsx next to the drawings: Summary (OK or FIX per check), Details (what was found, how to fix it), Checks (what each one means).

  4. Fix, and run again until every row passes. Then save.

What YYC checks

  • Purged: no unused layers, styles, blocks or layer filters. No empty text or empty blocks.
  • Nothing on 0 or DEFPOINTS except inside block definitions.
  • AUDIT comes back clean.
  • Colour and linetype by layer; lineweights at Default.
  • Dimensions associative, with no overridden text.
  • Real linetypes from CAA.LIN, not dashes drawn as segments. Circles are circles. By eye.
  • Viewports on VIEWPORT# layers, no-plot, locked, at the right scale.
  • Main layout active; prints with no extra page setup; nothing stranded off-sheet.
10Ribbon panel Deliver

File description and transmittal

Every delivery is one zip per discipline, with a File Description PDF beside them listing every drawing from every consultant.

Run

  1. Ask each consultant for their drawing list early.

    File names must match their DWGs character for character.

  2. YYCFILELIST on the delivery folder

    Writes FileDescription_list.txt: every drawing with the sheet title read from its titleblock, grouped by discipline. It also flags badly named files.

  3. Open YYC File Description - Template.docx from the Kit folder in Word.

    Fill the header, paste your list and each consultant’s under it, check every line, then save as Word and as PDF.

  4. YYCTRANSMIT on the delivery folder

    Asks the stage and phase, then makes one zip per discipline: drawings, xrefs re-pathed (not bound), CAA fonts, CAA.SHX, the CTB and a transmittal. Open one and compare it with ETRANSMIT before the first real delivery.

Not in the zipsThe File Description, Word or PDF, doesn’t go inside any eTransmit zip. The PDF sits next to them in the delivery folder.

Being testedYYCFILEDESC tries to build the whole File Description for you, Word and PDF. Give it a go and check the result; if it doesn’t work, use the template as above.

Toolkit commands

Every command, in process order. YYCHELP in AutoCAD shows the same list with a Run button.

CommandWhat it does
How the toolkit works

It works through AutoCAD’s ActiveX object model, so the same code runs on the open drawing or a whole folder through YYCBATCH. Full AutoCAD on Windows only, not LT or Mac.

  • Checks only report: YYCQA and YYCZERO change nothing.
  • Each viewport and layer fix undoes in one step.
  • YYCBATCH backs up the folder first, saves as AutoCAD 2018 and writes a log.
Once a terminal’s first sheet works

Run the rest through YYCBATCH: Pagesetup, YYCSCHEDULES per sheet, then Align → Vplayers → Lwdefault → Laysync → Clean, and finish with one Final → Qa batch.

Left out on purpose because they break YYC rules: SetArialFont, RecursiveExplode, MakeBlockInFiles, ProcessCurrentDrawing, UpdateDimStyles, ImportMLEADERStyle, PSPC.

Layer naming

Discipline - Major - Minor - Status, up to four characters each: A-WALL-FULL, A-WALL-DEMO.

Disciplines: A Architectural · C Civil · E Electrical · F Fire Protection · G General · I Interiors · L Landscape · M Mechanical · P Plumbing · S Structural · T Telecom · V Survey.

One item type, one layer, across the whole set. A new layer needs Spatial Data Services approval before it’s used; approved ones go in YYC Approved Layers.csv in the Kit folder.

Three rulesTurn the view, never the geometry. Colour and linetype by layer, never by object. Nothing on 0 or DEFPOINTS except inside blocks.
